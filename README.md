# 사건 게임 에디터 0.1.61

Android 8.0 이상용 세로 화면 제작 에디터. 인터넷 없이 실행합니다.

첫 화면에서 1 · 에디터 / 2 · 플레이를 고릅니다. 에디터 안에서 이야기 / 보유 항목 / 테스트 탭을 사용합니다.
위·아래 그림, 중앙 고정 대화창(너비 74%, 최대 높이 260 CSS px, 작은 화면은 화면 높이의 34%)을 사용합니다.
이름·대사·선택지는 같은 네모 안에 있고, 긴 내용은 네모 내부에서 스크롤합니다.

## 0.1.61 시간 제한 선택지

- 선택지 탭의 **⏱ 시간 제한**으로 사건마다 **3~30초**를 정하고, 시간이 다 되면 골라질 선택지를 고릅니다. 시간은 대사가 다 나온 뒤부터 흐르고, 가방 · 이전 대화 · 배경 보기 · 획득 그림이 열려 있으면 멈춥니다. 정한 선택지가 막혀 있으면 고를 수 있는 첫 선택지가 골라집니다. 테스트에서는 ⏸로 멈출 수 있습니다. 자세히: `RELEASE-v0.1.61.md`.

## 0.1.60 호감도

- 보유 항목에 새 종류 **호감도**(인물과의 관계, **-5~+5**)가 생겼습니다. 선택지 → **변화** 탭에서 인물마다 ±로 올리고 내리며(3명까지), 내려도 선택지가 잠기지 않습니다. 조건은 **이상 / 이하**, 대사 변주는 `{민준>=3? …}` · `{민준<=-2? …}`처럼 씁니다. 플레이어는 가방의 **호감** 탭과 ‘민준 ♥ +1’ 알림으로 보고, 항목마다 **플레이어에게 숨김**을 켤 수 있습니다. 자세히: `RELEASE-v0.1.60.md`.

## 0.1.59 랜덤 등장 조건 · 무게

- 랜덤 인카운터의 내용 탭에서 **🎲 버튼**(예: `🎲 한 번`, `🎲 반복 ×2 *`)을 누르면 **랜덤 등장** 창이 열립니다. 한 번만, **무게 1~10**(기본 5, 이 묶음에서의 예상 % 표시), **등장 조건**(3개까지, 있을 때/없을 때, 모두 만족/하나라도)을 정합니다. 구조도 🎲 목록에도 사건마다 %가 보입니다. 자세히: `RELEASE-v0.1.59.md`.

## 0.1.58 조건 여러 개 · 여러 개 얻기·잃기

- 선택지의 필요한 보유 항목을 **3개까지** 달고, 조건마다 ‘있을 때 / 없을 때’를, 묶어서 ‘모두 만족 / 하나라도’를 고릅니다. ‘능력 보유 시 다른 결과’의 보유 조건도 똑같이 3개까지입니다.
- 한 선택지로 **3개까지 얻고, 3개까지 잃습니다**(다른 결과도 같음). 잃을 것이 하나라도 모자라면 지금처럼 선택지가 잠깁니다. 자세히: `RELEASE-v0.1.58.md`.

## 0.1.57 찾기 넓히기 · 글자 속도

- 사건 찾기가 선택지 문구 · 엔딩 이름 · 사망 사유 · 말하는 사람까지 찾고, 이름이 아닌 곳에서 찾으면 ‘선택지에서’처럼 어디서 찾았는지 알려 줍니다. 선택지에서 찾은 사건은 선택지 탭으로 열립니다.
- 가방 → 설정에 **글자 속도**(느리게 · 보통 · 빠르게 · 바로)를 넣었습니다. 설정이 한 화면에 안 들어가면 다른 탭처럼 쪽으로 나눕니다. 자세히: `RELEASE-v0.1.57.md`.

## 0.1.56 기능 둘러보기 예제

- 그림 모음 · 기본 소리 · 연출 · 변주 · 랜덤 묶음 · 엔딩/사망을 한 판에 보여 주는 예제 「기능 둘러보기 · 비 오는 학교」를 넣고, 예제로 새 게임이 이 예제를 만들게 고쳤습니다. 자세히: `RELEASE-v0.1.56.md`.

## 0.1.55 화면 점검 다듬기

- 새 게임에 시작 능력 경고가 미리 뜨지 않고, 편집 화면 위에 게임 이름을 보여 주며, 헷갈리던 버튼 이름(관리 · 기본 그림 설정 · 기본으로 · 사건 BGM)을 고쳤습니다. 자세히: `RELEASE-v0.1.55.md`.

## 0.1.54 조건 이름 오타 경고 · 기호 버튼 확장 · 설명서 연결

- 이름이 틀려 조건이 방문마다 문장으로 읽히는 변주를 미리보기와 이야기 점검이 알려 줍니다. 기호 버튼을 말하는 사람 · 선택지 문구에서도 쓰고, ? 도움말에서 사이트의 자세한 설명서를 엽니다. 자세히: `RELEASE-v0.1.54.md`.

## 0.1.53 기호 버튼

- 내용 탭 변주 버튼 줄의 **기호**를 누르고 기호를 고르면 커서 자리에 들어갑니다(두 번 누르기, 키보드 유지). 괄호 밖에서는 `{~|}` · `{=}`처럼 괄호까지 넣습니다. 자세히: `RELEASE-v0.1.53.md`.

## 0.1.52 그림 모음 (기본 배경 · 인물)

- 한 그림체로 그린 기본 배경 9곳(교실 · 학교 복도 · 교문 앞 · 학교 옥상 · 거리 · 집 앞 · 남자 방 · 여자 방 · 공원) × 낮 · 노을 · 밤, 남학생 · 여학생 × 표정 5가지. 그림 탭 · 기본 그림 · 연출 → 인물의 **그림 모음**에서 고릅니다. 인물은 상반신 또는 전신으로 넣고, 크레딧이 필요 없습니다. 자세히: `RELEASE-v0.1.52.md`.

## 0.1.51 키보드가 올라와도 겹치지 않게

대사를 쓰려고 키보드가 올라오면 대사 칸과 변주 버튼만 남기고 나머지는 잠시 숨겨, 대사 칸이 버튼·미리보기와 겹치지 않습니다. 자세한 내용은 [RELEASE-v0.1.51.md](RELEASE-v0.1.51.md).

## 0.1.50 랜덤 보상 예제 빼기

‘랜덤 보상 예제 · 비가 그치기 전’을 앱에서 뺐습니다. 새로 설치하면 이 예제가 추가되지 않고 APK가 약 2.4MB(11.8→9.4MB) 작아집니다. 이미 설치된 폰의 예제와 진행은 그대로 남으며, 게임 관리에서 지울 수 있습니다. 자세한 내용은 [RELEASE-v0.1.50.md](RELEASE-v0.1.50.md).

## 0.1.49 대사 변주 괄호 자동 완성

`{`만 치면 `{|}`가 함께 들어가고, 괄호 안에서는 다음 칸 › · 괄호 밖 » 버튼으로 이동합니다. 쓰지 않은 빈 칸은 뜻이 같은 곳에서만 정리합니다. 자세한 내용은 [RELEASE-v0.1.49.md](RELEASE-v0.1.49.md).

## 0.1.48 🎲 랜덤 묶음

랜덤 인카운터를 묶음(예: 1챕터·2챕터)으로 나눠, 선택지마다 어느 묶음에서 뽑을지 고릅니다. 구조도에는 묶음마다 🎲가 따로 보입니다. 자세한 내용은 [RELEASE-v0.1.48.md](RELEASE-v0.1.48.md).

## 0.1.47 구조도에서 랜덤 인카운터 편집

구조도의 🎲를 누르면 랜덤으로 뽑히는 사건 목록이 열려 체크로 넣고 빼고, ‘한 번만’을 정하고, 사건을 열 수 있습니다. 그리기로 🎲 → 네모(목록에 넣기), 네모·동그라미 → 🎲(랜덤으로 잇기)도 됩니다. 자세한 내용은 [RELEASE-v0.1.47.md](RELEASE-v0.1.47.md).

## 0.1.46 뒤로 가기는 직전 화면으로

뒤로 가기가 어디서든 바로 전 화면(탭·사건·사건 찾기·구조도·게임 목록·첫 화면 순)으로 돌아갑니다. 자세한 내용은 [RELEASE-v0.1.46.md](RELEASE-v0.1.46.md).

## 0.1.45 구조도 이동 모드 · 랜덤 연결

구조도 왼쪽 아래 ✋ 이동 · ✏ 그리기 전환: 이동 모드에서는 빈 곳을 끌면 화면이, 네모·동그라미를 끌면 그 사건·선택지가 옮겨지고, 그리기 모드에서만 그립니다. 랜덤 인카운터로 가는 선택지는 🎲 동그라미로 모여 뽑힐 수 있는 사건들로 점선이 이어집니다. 자세한 내용은 [RELEASE-v0.1.45.md](RELEASE-v0.1.45.md).

## 0.1.44 구조도

사건 찾기 → **구조도**에서 게임 전체를 네모(사건)·동그라미(선택지)·화살표로 봅니다. 한 손가락으로 네모를 그리면 새 사건, 동그라미는 선택지, 선은 연결이 되고, 두 손가락으로 확대·축소·이동합니다. 자세한 내용은 [RELEASE-v0.1.44.md](RELEASE-v0.1.44.md).

## 0.1.43 사건 목록에서 바로 삭제

사건 찾기 목록의 줄마다 ✕ 버튼으로 사건을 지울 수 있고, 지운 뒤 같은 목록으로 돌아옵니다. 자세한 내용은 [RELEASE-v0.1.43.md](RELEASE-v0.1.43.md).

## 0.1.42 사망 장면 소리 · 연출 소리 우선

사망 장면에 오면 그 장면의 연출·BGM·대사 소리가 나오고, 기본 ‘사망’ 알림음은 장면에 소리가 없을 때만 납니다. 연출의 한 번 나는 소리가 효과음보다 우선하며(기본 알림음은 생략, 작가가 고른 효과음은 작게), 기본 알림음 크기를 연출 소리와 맞췄습니다. 자세한 내용은 [RELEASE-v0.1.42.md](RELEASE-v0.1.42.md).

## 0.1.41 사망 장면 · 갤러리에서 그림 고르기

사건의 진행 방식에서 **사망 장면(특수 사망)**이나 **엔딩 장면**을 고르면, 그 장면에 오는 순간 게임이 끝나고 장면마다 다른 대사·그림·연출·사망 사유가 나옵니다. 체력·멘탈 0으로 죽는 일반 사망(게임 관리의 ‘일반 사망 연출’)과 따로 표시·기록됩니다. 그림 불러오기는 갤러리 앱으로 열리고, 체력·멘탈·돈 변화 칸에는 ± 버튼이 생겼습니다. 자세한 내용은 [RELEASE-v0.1.41.md](RELEASE-v0.1.41.md).

## 0.1.40 기본 소리 크기·길이 맞춤

기본 소리를 귀로 느끼는 크기(EBU R128 LUFS) 기준으로 다시 맞췄습니다. 효과음은 가장 큰 순간을 −14 LUFS로, 배경 소리는 평균 −26, BGM은 −19로 맞췄고, 3초가 넘던 효과음은 3초(천둥·땅울림·종·박수는 3.5~5초)로 줄였습니다. 자세한 내용은 [RELEASE-v0.1.40.md](RELEASE-v0.1.40.md).

## 0.1.39 모든 화면을 스크롤 없이

모든 탭·창이 휴대폰 한 화면에 들어옵니다. 긴 목록은 쪽으로, 긴 입력 창은 탭으로 나눴고, 줄을 누르면 고치고 드문 동작(복제·삭제·순서)은 그 창 안으로 모았습니다. ‘선택 결과’ 탭은 ‘선택지’로 이름을 바꿨습니다. 자세한 내용은 [RELEASE-v0.1.39.md](RELEASE-v0.1.39.md).

## 0.1.38 연출 효과음 · 기본 소리 모음

날씨·순간 효과·전환·인물 등장에 어울리는 소리가 기본으로 납니다(위치별·게임 전체 끄기, 크기 조절). 소리 탭 → **기본 소리**에서 효과음 42 · 환경음 20 · 배경음악 13곡을 고릅니다. 배경음악(CC BY)은 크레딧 화면에 자동 표시됩니다. 자세한 내용은 [RELEASE-v0.1.38.md](RELEASE-v0.1.38.md), 출처는 [SOUND-CREDITS.md](SOUND-CREDITS.md).

## 0.1.37 비스듬한 비·낙엽이 화면 끝까지

## 연출 예시 모음 (다운로드 사이트)

연출 효과 86가지가 실제로 어떻게 움직이는지 [다운로드 사이트](https://stockyandere.github.io/myapps/#/event-game-editor/effects)의 **연출** 탭에서 볼 수 있습니다. 예시는 `node make-fx-gallery.cjs <myapps>/apps/event-game-editor/fx`로 이 저장소의 `stage-fx.js`를 그대로 녹화해 만듭니다(시간을 한 프레임씩 진행해 매번 같은 결과, 움직이는 WebP 240px). 효과를 바꾸면 다시 실행하세요. `publish-release.sh`가 쓰는 `release/update.json`에는 사이트용 `apkUrl`·`publishedAt`도 들어갑니다.

## 0.1.36 프리셋 두 줄 · 다시 누르면 취소 · 꾹 누르면 미리보기

프리셋은 두 줄 페이지([1 2 ‹ ›], 옆으로 밀기). 고른 것을 다시 누르면 취소, 어디서든 꾹 누르면 지금 연출 전체 미리보기(미리보기 버튼 없음). 자세한 내용은 [RELEASE-v0.1.36.md](RELEASE-v0.1.36.md).

## 0.1.33 연출 탭 정리

연출 탭을 위치 탭 [전체 · 위 그림 · 아래 그림] + 한 줄 도구 막대(미리보기 팝업 · 프리셋 · ⋯) + 이름/선택 한 줄 항목으로 다시 배치해 스크롤을 줄였습니다. 자세한 내용은 [RELEASE-v0.1.33.md](RELEASE-v0.1.33.md).

## 0.1.32 에디터 자동 업데이트

에디터가 공개 저장소의 `release/update.json`을 확인해 새 버전을 받아 둡니다. 같은 서명키로 서명된 것만 받아 둡니다. 처음 한 번 '알 수 없는 앱 설치' 허용과 설치 확인을 하면, 그다음부터는 Android 12 이상에서 에디터를 나가 있는 동안 자동으로 설치합니다. 첫 화면에서 끄고 켤 수 있습니다. 자세한 내용은 [RELEASE-v0.1.32.md](RELEASE-v0.1.32.md).

## 0.1.31 연출 적용 위치

## 0.1.24 대사 변주 · 기억

같은 사건이라도 지난 선택·보유 상태·방문 횟수에 따라 대사의 한두 문장과 선택지 하나만 달라지게 합니다. 자세한 내용은 [RELEASE-v0.1.24.md](RELEASE-v0.1.24.md), 참고 사례와 결정 근거(코드 언어 유지 포함)는 [Variations-Research.md](Variations-Research.md).

- **대사 변주 `{ }`**: `{용기? 들어간다|망설인다}`, `{!우산? 젖었다}`, `{돈>=2? …}`, `{처음|또|계속}`(방문마다), `{&아침|점심|저녁}`, `{~무작위|문구}`, `{@사건 이름? …}`, `{=돈}`. 대사·말하는 사람·선택지 문구에서 쓰고 겹쳐 쓸 수 있습니다.
- **내용 탭**: 문구를 선택하고 `＋ 조건` → 항목 고르기로 감쌉니다. 상태 칩을 눌러 같은 대사가 어떻게 바뀌는지 바로 보고, 대사 아래 선택지 목록에서 선택지를 고치고 추가합니다. 이 사건으로 오는 길로 이동합니다.
- **기억**: 가방에 보이지 않는 표시. 선택 결과 → 이 선택을 기억(버튼 한 번으로 만들기). 조건·대사 변주·숨김 선택지에 씁니다.
- **선택지**: 없을 때만 선택 가능, 안 맞으면 숨김.
- **보유 항목 → 이름 누르기**: 얻는 곳·쓰는 곳 모아 보기. 이름을 바꾸면 대사 속 참조도 함께 바뀝니다.
- **예제 · 같은 골목, 다른 밤**: 변주만으로 만든 8장면 예제를 한 번 추가합니다.
- 입력창의 오류 안내가 표시되지 않던 문제를 고쳤습니다.

검증: `test-variations.cjs`, `test-variations-browser.cjs`(3개 모바일 크기).

## 0.1.17 기본 그림·대체 문구

**이야기 → 그림 → 기본 그림·대체 문구**, 또는 **게임 관리(⋯) → 기본 그림·대체 문구**에서 이 게임의 위·아래 칸을 각각 설정합니다. 그림 선택/제거와 최대 300자 대체 문구를 입력하며 자동 저장합니다. 기본 그림도 없는 경우 대체 문구를 표시하고, 문구까지 비우면 조용히 빈 칸으로 표시합니다. 그림을 읽지 못한 경우에도 대체 문구를 표시합니다.

사건 그림이 기본 그림보다 우선합니다. 사건의 **기본 사용**은 해당 사건 그림을 지우고 게임의 기본 설정으로 돌아가며, **비우기**는 그림·대체 문구 모두 표시하지 않는 의도적인 빈 칸입니다. 위/아래 그림만 사용하거나 전체 그림 모드인 경우 사용하지 않는 칸에는 기본 문구도 표시하지 않습니다. 위치·크기 맞춤은 기존 사건 그림 조절을 그대로 사용합니다.

기존 게임의 `sampleImage`는 새 기본 설정을 만들기 전까지 기존 기본 그림으로 유지됩니다. 새로 설정한 칸의 그림을 제거하면 예제 사진이 다시 나타나지 않습니다. 기본 설정과 이미지 파일은 프로젝트에 포함하고 공유 이미지 저장/내보내기/되돌리기를 지원합니다. 편집 설정을 바꿔도 이미 저장된 플레이 버전과 진행을 덮어쓰지 않습니다. 플레이에 반영 후 새로 시작하면 변경된 기본 설정을 사용합니다.

검증: `test-default-art.cjs`, `test-default-art-browser.cjs`의 3개 모바일 크기에서 기본 그림 가져오기/제거, 위·아래 대체 문구, 미리보기와 플레이 일치, 기본 사용과 의도적 비우기, 자동 저장과 재시작, 플레이 버전 분리, 손상된 그림의 문구 처리, 고정 네모와 외부 스크롤 없음. 실제 안드로이드 기기 조작은 별도 확인 대상입니다.

## 0.1.16 이전 대화와 배경 보기

플레이/테스트의 고정 대화창 바로 아래에 **이전 대화 보기 / 배경 보기** 두 버튼을 붙였습니다. 대화창과 그림의 크기는 그대로이며 버튼은 대화창의 스크롤 영역 밖에 있습니다.

- **이전 대화 보기**: 화면 높이 전체를 사용하는 팝업에서 지나간 대사와 선택한 문구를 시간순으로 읽습니다. 가장 최근 대화의 시작 위치로 열리며, 팝업 내용만 세로 스크롤합니다. 닫기/뒤로가기 한 번으로 플레이에 돌아갑니다.
- 중앙 네모에는 현재 대화와 선택지만 표시합니다. 이전 대화를 위로 올려 찾을 필요가 없습니다. 사건/랜덤 인카운터를 넘어간 대화도 따로 기록하고 이어하기에서 복원합니다.
- **배경 보기**: 중앙 네모·상태줄·두 버튼을 숨기고 원래 위·아래 또는 전체 그림을 감상합니다. 그림을 터치하거나 뒤로가기/ESC를 누르면 같은 대화로 돌아옵니다. 타이핑/선택/대화창 스크롤 위치를 유지하고 게임을 진행하지 않습니다. 타이핑은 두 보기 화면에서 잠깐 멈추며 BGM은 계속 재생합니다. 대사 소리는 보기 화면을 열 때 정지합니다.
- 기존 버전은 이미 지난 사건의 대사를 버렸기 때문에, 기존 진행에서는 남아 있는 분기 기록만 이어받습니다. 기록 누락이 있는 경우 팝업에서 표시합니다. 새로운 진행은 첫 장면부터 기록하며 반복 플레이의 저장 증가를 막기 위해 가장 최근 1,000회 대화를 보관합니다.
- 획득 그림이 나타난 중에도 두 버튼을 쓸 수 있고, 배경 보기에서는 획득 연출을 정리합니다. 이후 선택이나 보상을 자동으로 받지 않습니다. 보기 상태 자체는 저장하지 않아서 앱을 다시 열면 대화창이 보입니다. 제작 데이터와 플레이 버전은 바꾸지 않습니다.

검증: `test-reading.cjs`의 사건 간 기록/이어하기/기존 저장 호환/되돌리기/재시작/보상 기록 검사, `test-reading-browser.cjs`의 3개 세로 모바일 크기에서 전체 높이 팝업·복귀·타이핑 일시 정지·그림 위치 유지·획득 중 보기·BGM 유지·고정 대화창·외부 스크롤 없음. 실제 안드로이드 기기 조작은 별도 확인 대상입니다.

## 0.1.15 랜덤 보상과 보유 효과

- **이야기 → 선택 결과 → 랜덤 보상**: 후보 체크, 공통 획득 수량 설정. 후보에서 최대 3종을 같은 확률로 중복 없이 뽑고 플레이어가 하나를 선택합니다. 후보가 1~2종이면 모두 표시합니다. 이미 보유한 항목도 후보이며 수량이 늘어납니다. 보상 선택은 기존 대화창 안에 표시합니다.
- **보유 항목 → 수정 → 보유 효과**: 기본 효과 하나, 선택적으로 조합 효과 하나. 체력·멘탈·돈 소모 감소와 회복/획득 증가 6종을 지원합니다. 조합은 다른 항목도 1개 이상 보유하면 적용합니다. 각 효과는 보유 중 한 번씩 적용하며 레벨/개수에 따라 배수로 늘어나거나 항목이 자동 소모되지 않습니다. 다른 항목의 효과는 합산하며 손실은 0 아래로 역전되지 않고 회복은 자원 최대치를 지킵니다.
- 조건 분기와 효과는 **선택 직전** 보유 상태에서 계산합니다. 방금 획득한 보호 효과는 이미 치른 체력 소모를 취소하지 않습니다. 할인 후 비용으로 구매 가능 여부를 판단하되, 별도 체력·돈 보유 조건은 그대로 필요합니다. 선택지에 효과 이름과 적용 전후 비용을 표시하고 가방에 효과 설명을 표시합니다.
- **선택 결과 → 자원 변화 → 보유 효과 적용 안 함**: 스토리상 고정 대가에 사용합니다. 기본 결과와 조건별 대체 결과 모두에 적용됩니다. 보상은 선택 결과의 자원·소모·고정 획득 처리 후 표시하고, 보상을 고른 뒤 지정한 다음 사건으로 갑니다. 사망 시 보상은 주지 않습니다. 보상 후보는 진행에 저장하여 이어하기 때 다시 뽑지 않습니다.
- 기존 이야기 점검 보강: 빈 보상 후보는 오류, 획득 항목의 사용처 없음·보유 효과가 적용될 자원 변화 없음·획득 후 사용 장면에 도달할 구조적 경로 없음·조합 상대의 획득 위치 없음은 경고. 분기 보유량과 랜덤 결과를 모두 증명하지 않는 보수적 구조 검사입니다.
- **2 · 플레이 → 랜덤 보상 예제 · 비가 그치기 전 → 비상 가방에서 남은 비상 물품 선택**. 보호 부적/흥정/차의 온기/붕대/간식 후보, 보호 부적 + 용기 조합을 사용합니다. 37장면·97선택지·14항목. 예전 예제의 수정본과 플레이 진행을 덮어쓰지 않고 새 예제를 한 번 추가합니다.

별도 보상 화면·조합 메뉴·플레이 패널을 만들지 않았습니다. 희귀도·가중치·확률 발동·효과 트리·자동 조합 제작은 이번 범위에서 제외했습니다. 아이템은 랜덤 사건의 등장 대상을 바꾸지 않습니다.

검증: `test-rogue.cjs`, (v0.1.49까지) `test-rogue-browser.cjs`의 3개 모바일 크기에서 제작/자동 저장/대기 보상 이어하기/조합 적용/삭제 참조 정리/고정 대화창/외부 스크롤 없음, 확장 예제 6,000회 실제 규칙 경로 탐색. 실기기 성능·음향은 별도 확인해야 합니다.

## 0.1.14 확장 완성 예제

모든 보유 항목에 사용처가 있고, 능력 레벨·아이템 수량·소모·조건별 다른 결과·자원 요구·회복·상태 해제·체력/멘탈 사망을 사용합니다. 새 그림 4개, 직접 합성한 BGM 3곡과 짧은 소리 12개, 기존 9종 기본 효과음을 포함합니다. 대사 소리는 발화 차임/상황 효과음이며 녹음 음성은 아닙니다. 타이핑과 획득 그림/소리의 터치 생략, BGM 유지/전환/정지/반복 해제도 실제 장면에 적용합니다.

(v0.1.50부터 이 예제는 앱에 들어 있지 않습니다.) 자세한 사용 위치와 결말 경로는 [Example-Guide.md](Example-Guide.md), 제작 프롬프트는 [Example-Art-Prompts.md](Example-Art-Prompts.md). 제작 재료는 `example-media/`, 데이터 생성기는 `make-example.py`, 음원 합성기는 `make-example-audio.py`입니다. 런타임 예제 파일은 공유 에셋 표로 중복을 줄였습니다. 실제 플레이 화면에 추가 메뉴나 알림 영역을 만들지 않았습니다.

검증: `node test-example.cjs`의 실제 규칙 경로 탐색, `test-example-browser.cjs`의 3개 모바일 크기/37개 장면/실제 플레이/미디어/이어하기 검사. 기존 오디오·핵심 규칙·저장·모바일 UI 검사도 수행했습니다. 실제 안드로이드 기기 재생 품질과 성능은 별도 확인 대상입니다.

## 0.1.13 대사 음성·효과음·BGM

**이야기 → 사건 선택 → 소리**에서 장면의 대사 음성 또는 상황 효과음을 불러옵니다. 장면 시작 때 한 번 재생하고, 미리 듣기·파일 교체·제거·음량 조절을 지원합니다. 대사 타이핑을 터치로 넘기면 음성도 멈춥니다. 글자가 자연스럽게 끝나는 경우 음성은 끝까지 재생합니다. 새로운 사건이나 재시작 때 다시 재생하며, 가방 열기나 같은 사건 재렌더는 반복 재생하지 않습니다.

같은 탭의 **BGM**은 이전 곡 유지 / 새 곡 재생 / 끄기로 설정합니다. 새 곡은 파일·음량·반복 재생 여부를 지정합니다. **게임 공통 소리**를 펼치면 게임 기본 BGM과 종류별 기본 효과음을 설정합니다. 기본 BGM은 첫 사건부터 사용하고 사건별 설정으로 바꿀 수 있습니다. 같은 곡을 유지하면 재생 위치가 이어집니다. 반복을 끈 곡은 끝난 뒤 가방이나 음소거를 조작해도 처음부터 반복하지 않습니다. 이어하기는 마지막 BGM과 재생 위치를 복원합니다.

**보유 항목 → 수정 → 획득 효과음**에서 해당 능력·아이템·상태의 획득 소리를 따로 지정합니다. 효과음 우선순위는 항목별 지정 → 게임 공통 지정 → 앱 기본 소리입니다. 체력·멘탈·돈 변화, 회복·손실·사망·특별 획득 등 9가지 기본 효과음도 교체할 수 있습니다. 획득 알림이 끝나거나 터치로 넘기면 그 효과음은 멈춥니다. BGM은 알림 생략으로 멈추지 않습니다.

음성이 재생되는 동안 BGM은 설정 음량의 40%로 잠깐 낮아졌다가 돌아옵니다. 획득 그림을 보여주는 동안 다음 대사 음성은 기다렸다가 그림 연출이 끝난 뒤 재생합니다. 가방의 스피커는 전체 소리를 켜고 끕니다. 가방 내부의 **재생 음량**에서 대사·효과음·BGM의 상대 음량을 따로 조절하며 재실행 후에도 유지합니다. 제작자가 설정한 파일 음량과 플레이어 상대 음량을 곱해 실제 재생 음량을 적용합니다.

가져온 소리는 앱에 복사하여 보관하므로 원본 파일을 옮겨도 플레이에 사용합니다. MP3/WAV/M4A/OGG/AAC/FLAC/WEBM을 받을 수 있으며 파일을 선택한 기기에서 재생 가능한지 확인합니다. 짧은 소리는 파일당 12MB, BGM은 24MB까지이고 기존 전체 저장 제한은 약 100MB입니다. 같은 소리를 편집본·플레이본·진행·입력 초안에서 공유해 중복 저장하지 않습니다. JSON 내보내기에 소리를 포함하며 기존 내보내기·가져오기 제한 50MB를 적용합니다. 초과하면 안내합니다. 되돌리기와 미완성 항목 초안 복원에도 소리를 보관합니다.

화면 이동·앱 숨김에서 음성·효과음·미리 듣기를 멈추고 BGM을 일시 정지합니다. 앱으로 돌아오면 BGM은 이어서 재생합니다. 소리 탭과 펼친 설정은 기존 편집 영역 내부에서만 스크롤합니다. 실제 플레이에 추가 상단·하단 메뉴를 만들지 않습니다.

## 0.1.12 사건 앞뒤 이동

사건 이름 왼쪽·오른쪽의 화살표로 목록을 열지 않고 이전·다음 사건을 편집합니다. 사건 목록의 순서를 따르며 랜덤·분기·스토리 사건 모두 포함합니다. 현재 편집 탭(내용/선택 결과/위·아래 그림)을 유지하고 입력 내용은 기존 자동 저장을 사용합니다. 첫 사건의 이전 화살표, 마지막 사건의 다음 화살표는 비활성화합니다. 사건 이름을 누르는 검색 목록도 계속 사용할 수 있습니다. 기존 도구 줄의 높이와 외부 스크롤 제한을 유지합니다.

## 0.1.11 획득 효과와 사운드

초록색 단색 알림을 어두운 바탕의 색상 강조, 종류별 아이콘 등장, 네모 테두리의 빛, 짧은 빛 스침과 반짝임으로 변경했습니다. 능력은 금색, 아이템은 청록색, 상태는 보라색, 돈은 황금색, 회복은 민트색, 손실·사망은 붉은색입니다. 작은 상태 표시줄과 기존 대화 네모 안에서만 연출하고, 그림이 없으면 기존 대사를 유지합니다. 그림이 있으면 저장된 표시 위치로 채웁니다.

보유 항목 → 수정 → **획득 연출 · 그림과 강조**에서 **특별 획득으로 강조**를 선택하면 금빛 효과, 더 많은 반짝임, 약 3.4초 표시, 특별 획득 소리를 사용합니다. 그림 없이도 적용되며 자동 저장·플레이 반영·내보내기·진행 복원에 포함됩니다. 기본 획득은 약 2.8초, 긴 알림은 최대 8초입니다.

능력·아이템·상태·돈·회복·손실·사망·특별 획득 및 손실과 획득이 함께 일어난 경우에 서로 다른 짧은 효과음을 냅니다. 모두 `make-sfx.py`로 직접 합성한 WAV이며 `assets/sfx/`에 포함되어 인터넷이 필요하지 않습니다. 기존 게임의 음원·이미지를 가져오지 않았습니다. 가방을 열고 제목 오른쪽 스피커를 누르면 켜거나 끌 수 있고 앱 재실행 후에도 설정을 유지합니다.

상태줄/획득 그림 터치로 연출과 소리를 즉시 멈춥니다. 겹친 소리는 끊고 최신 변화만 재생합니다. 화면 이동·앱 숨김에서도 정리하며 시스템 모션 감소 설정에서는 아이콘과 색상으로 표시합니다. 저장 대기 중 빠르게 화면을 나가거나 재실행하는 경우에도 요청된 저장 작업 완료를 기다리도록 수정했습니다.

조사 근거와 이번 앱에 맞춰 만든 연출의 범위는 `Effects-Research.md`에 기록했습니다.

## 0.1.10 획득 그림 위치 조정

획득 연출 그림을 여백 없이 채우는 방식으로 변경했습니다. 보유 항목 수정에서 미리보기 그림을 드래그하여 보여줄 부분을 맞춥니다. 미리보기는 플레이의 대화 네모와 같은 비율로 표시되며, 가로·세로 위치는 자동 저장하고 실제 연출·플레이 반영·파일 내보내기·진행 저장에 함께 보관합니다. 중앙 버튼으로 위치를 초기화할 수 있습니다. 방향키로 이동, Shift+방향키로 더 크게 이동, Home으로 중앙 복귀도 지원합니다. 새 그림을 선택하면 중앙에서 시작합니다. 기존 그림은 위치 설정이 없어도 중앙에서 표시됩니다. 네모 크기와 외부 스크롤 제한은 그대로입니다.

## 0.1.9 사진 전체 표시

획득 연출과 편집 미리보기에서 세로·가로·정사각형 사진을 자르지 않고 원래 비율대로 네모 안에 최대한 크게 표시합니다. 대화 네모의 크기와 스크롤 방식은 그대로 유지합니다.

## 0.1.8 획득 연출

- 상태 표시줄의 `용기 +1`, `체력 -2` 같은 알림은 터치 또는 Enter/Space로 즉시 넘길 수 있습니다. 가방은 알림 중에도 독립적으로 열립니다.
- **보유 항목 → 수정 → 획득 연출 그림 · 선택**에서 능력·아이템·상태마다 그림을 직접 넣거나 제거합니다. 입력과 그림은 자동 저장되며 플레이에 반영한 게임과 내보내기 파일에도 포함됩니다.
- 그림이 있는 항목을 획득하면 상태 표시줄에 실제 변화량을 표시하고 기존 대화 네모를 그림으로 채워 약 2.8초간 보여줍니다. 긴 알림이면 최대 8초까지 표시합니다. 새 창이나 별도 알림 영역을 만들지 않고 네모 크기와 위치를 유지합니다. 0.1.10부터 여백 없이 채우고 미리보기에서 드래그하여 표시 위치를 맞춥니다. 실제 획득 연출에도 저장된 위치를 적용합니다.
- 상태 표시줄 또는 획득 그림을 터치하면 바로 대화로 돌아옵니다. 같은 터치로 다음 선택지가 실행되지 않으며 빠른 연속 입력에도 짧은 보호 시간을 둡니다. 다음 대사의 타이핑은 그림 연출 동안 멈췄다가 끝나면 이어집니다.
- 그림이 없거나 불러올 수 없으면 대사를 그대로 표시합니다. 소모만 발생했을 때는 획득 그림을 표시하지 않습니다. 기존 게임은 수정 없이 기존 텍스트 방식으로 실행됩니다.
- 모션 감소 설정에서는 등장 애니메이션 없이 보여주며 터치로 넘기는 기능은 유지됩니다. 그림 중에도 보유 목록과 뒤로가기 저장이 작동합니다.

## 0.1.7 간단한 제작 흐름

- 상단 도구 줄을 정리했습니다. 되돌리기는 작은 아이콘, 다시 실행은 복구할 기록이 있을 때만 표시합니다. 이야기 점검은 ⋯ 메뉴에 있고 발견된 문제 수를 작은 배지로 표시합니다.
- 현재 사건 이름을 누르면 이름 검색 가능한 사건 목록을 엽니다. 가로로 끝없이 밀지 않습니다.
- 선택 결과에서 항목을 고른 경우에만 수량 입력칸을 표시합니다. 체력·멘탈·돈 변화는 접을 수 있는 한 줄 요약으로 시작합니다.
- 선택 결과의 항목 선택에서 새 능력·아이템·상태를 만들고 즉시 선택할 수 있습니다. 다음 진행에서도 새 분기 사건을 만들어 연결하고 바로 내용을 작성합니다.
- 새 사건은 현재 사건의 화자와 위·아래 그림 배치를 재사용합니다. 선택지를 복제할 수 있고, 기존 사건의 그림도 이전 사건에서 재사용할 수 있습니다.
- 그림 탭은 실제 플레이 화면 비율과 중앙 대화창 위치를 미리 보여 줍니다. 표시 위치/맞춤 변경이 즉시 반영됩니다. 전체 배경에서는 사용하지 않는 아래 그림 조작을 숨깁니다.
- ‘능력 보유 시 다른 결과’는 기본 결과에 더하지 않고 대체하는 기존 기능입니다. 대체 결과도 획득·소모 수량을 지정할 수 있습니다.
- 체력·멘탈 감소를 선택 전에 표시합니다. 공개를 원하지 않는 선택지는 ‘체력·멘탈 소모를 선택 전에 표시’를 해제합니다. 돈·보유 항목의 필수 조건은 계속 표시합니다. 공개된 소모로 생존 자원이 0이 될 경우 사망 위험을 표시합니다.
- 가방의 전체 목록 위에 최근 변화 3개를 표시합니다. 최근 변화 기록은 최대 30개를 진행 데이터에 보관하며 장면 전환 후에도 유지합니다. 이전 저장 진행에 기록이 없으면 빈 기록에서 시작합니다.
- 알림 중에도 가방은 눌러 보유 상태를 확인할 수 있습니다. 별도 하단 알림창은 추가하지 않았습니다.
- 에디터 테스트 상단의 ‘조건 비교’에서 현재 장면에 필요한 능력/아이템을 미보유·보유로 바꾸고 결과와 다음 진행을 비교합니다. 장면 이동이나 프로젝트 시작 상태 변경은 없고, 테스트에서만 적용됩니다. 자원 수량은 전체 보유량 설정을 사용합니다.
- 화면 바깥 스크롤은 사용하지 않습니다. 사건 목록·편집 영역·입력창·보유창의 내부 영역에서만 스크롤합니다. 입력창 제목은 위에 유지하고 완료는 아래에 고정합니다.

## 0.1.6 대사 연출

- 실제 플레이와 에디터 테스트에서 새로운 대사가 약 30ms마다 한 글자씩 나타납니다. 한글·이모지의 조합 글자를 중간에 끊지 않습니다.
- 연출 중 네모 안을 터치하면 남은 글을 즉시 표시합니다. 이 터치는 선택지를 실행하지 않습니다. 빠른 연속 터치로 선택지가 눌리지 않게 짧은 보호 시간을 둡니다.
- 대사가 완성되면 선택지가 나타납니다. 대사와 선택지의 자리와 내부 스크롤 높이를 미리 확보하므로 연출 중 화면이 밀리지 않습니다.
- 이름·보유 상태·알림에는 타이핑 효과를 적용하지 않습니다. 보유 목록을 열거나 같은 장면의 화면을 다시 그려도 대사를 처음부터 반복하지 않습니다.
- Android 뒤로가기는 연출 중에도 즉시 저장 후 나갑니다. 앱을 숨기면 남은 글을 완성하고 저장합니다. 시스템 모션 감소 설정에서는 처음부터 전체 글을 표시합니다.

## 화면과 저장

- 에디터 목록에서 기존 게임을 선택하거나 새 게임을 만듭니다. 작성 내용은 자동 저장됩니다.
- 에디터 상단 **플레이에 반영**을 누르면 현재 편집본을 앱 내부 플레이 목록에 반영합니다. 작성 내용의 자동 저장과는 별개입니다. 파일 이름이나 폴더를 직접 고르지 않습니다. 새 게임과 예제 추가는 기존 게임을 덮어쓰지 않습니다.
- 플레이 목록에서 게임을 고르고, 게임별로 이어하기 또는 처음부터를 선택합니다. 실제 플레이는 편집 메뉴와 하단 탭 없이 화면을 넓게 사용합니다.
- 중앙 대화 네모 위에 붙은 **상태 표시줄**은 사람(체력), 하트(멘탈), 동전(돈), 가방(보유한 것) 아이콘만 표시합니다. 가방을 누르면 전체/능력/아이템/상태 목록을 확인합니다.
- 획득·소모·생존 자원 변화는 상태 표시줄의 가방 왼쪽 영역을 사용해 `체력 -2 · 멘탈 -1 · 붕대 +1`처럼 실제 변화량을 한 줄로 표시합니다. 평소 알림은 약 2.8초 뒤 아이콘으로 돌아갑니다. 긴 알림은 최대 8초간 가로로 읽게 표시합니다. 모션 감소 설정에서는 움직임 없이 직접 가로 스크롤할 수 있습니다.
- 실제 플레이에는 상단 메뉴·따로 떨어진 자원 바·하단 알림 영역·나가기 버튼이 없습니다. 그림 영역은 앱의 사용 가능한 화면 전체를 채웁니다.
- **Android 뒤로가기**는 현재 장면, 체력·멘탈·돈, 보유량, 이미 등장한 사건과 내부 분기 기록을 저장한 후 목록으로 돌아갑니다. 각 선택 뒤와 앱이 숨겨질 때에도 자동 저장합니다. 보유 목록이나 입력창이 열려 있을 때는 먼저 그 창을 닫습니다.
- 저장 실패 시 상태 표시줄에 안내하고 플레이 화면을 유지합니다. 뒤로가기를 다시 누르면 재시도합니다. 편집 내용과 플레이 진행은 별도로 보관하며, 에디터 테스트는 실제 진행을 바꾸지 않습니다.
- 게임이 수정되어도 진행 중인 플레이는 시작한 버전으로 이어집니다. 수정한 버전으로 플레이하려면 처음부터 시작합니다. 기존 진행이 있을 때 처음부터 시작하려면 확인합니다.
- 이전 버전의 단일 프로젝트는 게임 목록으로 자동 이전합니다. 플레이할 수 없는 연결 오류가 있는 경우 편집본만 이전하고 먼저 수정합니다.
- 그림은 여러 저장본에서 같은 그림을 공유해 파일에 중복 저장하지 않습니다. Android는 앱 내부 파일, 브라우저 미리보기는 IndexedDB를 사용합니다. 최대 게임 100개, 전체 저장 데이터 약 100MB 제한이 있습니다.
- 파일 가져오기·내보내기는 게임 관리(⋯)의 접힌 고급 항목에서 사용할 수 있습니다. 가져온 파일은 새 게임으로 추가됩니다.

## 이번 편집 UX 개선

- 되돌리기 / 다시 실행: 내용 수정, 선택 결과, 삭제, 순서 변경 등을 최근 20단계까지 복구합니다. 앱 실행 중의 기록이며 종료 후에는 남지 않습니다.
- 선택지·보유 항목 입력창은 유효한 입력을 자동 반영합니다. 뒤로가기·닫기로 나가도 수정이 유지됩니다. 미완성 입력은 별도 초안으로 보관하고 다시 열어 이어 씁니다. 앱 재실행 후에도 유지됩니다. 미완성 새 선택지는 진행 가능한 선택지 목록에 넣지 않습니다.
- 다른 장면에서 연결된 장면을 지우려면 대체 연결을 직접 선택해야 합니다. 삭제와 연결 변경을 함께 되돌릴 수 있습니다.
- 점검: 끊긴 연결, 빈 선택지, 비어 있는 랜덤 사건 풀, 접근 경로 없는 장면, 조건 때문에 모든 선택이 막힐 가능성 등을 표시합니다. 결과를 누르면 해당 장면으로 이동합니다.
- 여기서 테스트: 선택한 장면부터 시작합니다. 가방에서 테스트 보유량을 조절하거나 현재 장면을 편집하고, 테스트 진행을 30단계까지 되돌릴 수 있습니다.
- 편집을 바꾸지 않았다면 테스트 진행은 탭 이동 후에도 유지됩니다. 편집 내용이 바뀌면 새 테스트를 시작하고 안내합니다. 앱 종료 후 테스트 진행은 유지되지 않습니다.
- 저장 중 / 편집 저장됨 / 저장 실패를 표시합니다. Android 자동 저장은 이전 저장본을 별도로 보관합니다. 원본을 읽지 못하면 자동으로 덮어쓰지 않고 게임 관리에서 이전 저장 복구 또는 원본 파일 저장을 제공합니다.
- 브라우저는 현재 저장본과 이전 저장본을 하나의 IndexedDB 쓰기 작업으로 처리합니다. 저장 실패는 화면에서 안내합니다.
- 플레이 선택지는 최소 높이 48 CSS px를 유지합니다. 편집 도구는 화면을 확보하도록 작은 아이콘과 40~42 CSS px 조작 영역을 사용합니다. 실제 기기의 접근성 검증은 별도입니다.

점검은 연결과 입력의 정적 검사입니다. 보유 상태별 모든 플레이 경로의 완주 가능성을 증명하지 않습니다. 조건 분기와 소모량은 테스트 보유량을 바꾸면서 확인하세요.

## 서울 2033 참고 적용

- 상단 사람/하트/화폐 아이콘으로 체력·멘탈·돈을 표시합니다. 기본 최대치는 각각 3칸입니다.
- 체력 또는 멘탈 0이면 사망하며, 돈 0은 사망 조건이 아닙니다.
- 전체/능력/아이템/상태 분류는 유지합니다. 현재는 사용자 요청에 따라 중앙 상태 표시줄의 가방 아이콘과 획득 알림으로 표시합니다.
- 요구 조건을 만족하면 초록, 부족하면 빨강으로 표시하고 선택을 막습니다.
- 능력 레벨/보유 수량을 조건으로 지정하고 획득·소모 수량을 정할 수 있습니다.
- 같은 선택에 보유 조건별 대체 결과를 추가할 수 있습니다. 조건은 그 선택 직전 상태를 기준으로 판단합니다.
- 사건 내부 분기 중에는 이전 대사와 선택을 위로 스크롤해서 다시 읽을 수 있습니다.
- 새 프로젝트 및 새 예제는 시작 능력 2개를 무작위로 배정합니다. 능력은 2종 이상 등록하세요.
- 자원 변화는 실제 적용량을 상태 표시줄에 표시합니다. 최대치로 인해 회복이 줄어든 경우도 실제 회복량을 표시합니다. 보유 목록에서 전체 값을 확인할 수 있습니다.

## 진행 규칙

장면 종류는 스토리, 랜덤 인카운터, 내부 분기입니다. 목록 첫 장면에서 시작합니다.
선택 결과의 다음 진행은 사건 끝 · 다음 스토리 / 사건 끝 · 랜덤 인카운터 / 지정한 장면 / 이야기 끝 · 엔딩입니다.
다음 스토리는 마지막으로 진행한 스토리 뒤의 스토리 장면으로 이동합니다.
랜덤 인카운터는 인카운터로 등록한 장면 중 균등하게 뽑습니다. 한 번만 등장하도록 설정한 사건은 완료 후 제외됩니다.
내부 분기는 특정 선택지로 연결하고 사건 끝으로 설정해 본줄기로 돌아갑니다.
사용자 요청에 따라 보유 상태는 다음 사건 추첨이나 스토리 순서에 관여하지 않습니다.
돈을 지불하는 선택지는 충분한 돈이 있어야 선택할 수 있습니다.
남은 인카운터가 없으면 랜덤 진행 테스트가 종료됩니다.

## 기존 프로젝트와 새 예제

기존 자동 저장은 유지됩니다. 이전 버전 프로젝트에 없던 멘탈·돈은 각각 3으로 읽습니다.
이전 프로젝트의 시작 능력 설정은 그대로 유지되며, 보유 항목 탭에서 무작위 능력 2개를 선택할 수 있습니다.
새 예제는 게임 관리(⋯) → 예제로 새 게임으로 추가합니다. 기존 작업은 그대로 남습니다.
자동 저장과 이미지 포함 JSON 프로젝트 저장/불러오기를 지원합니다.
이전 별도 선택지 게임 에디터의 JSON 형식과는 다릅니다.
