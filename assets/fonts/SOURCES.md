# Bundled fonts
- NanumMyeongjo-Regular.ttf: unmodified Google Fonts binary from https://raw.githubusercontent.com/google/fonts/main/ofl/nanummyeongjo/NanumMyeongjo-Regular.ttf . License: NanumMyeongjo-OFL.txt.
- NotoSansKR-Bold.woff: weight 700 static instance of Noto Sans KR variable font, generated with fontTools.varLib.instancer and compressed to WOFF. Full character coverage is retained. The original variable font and OFL were reused from the existing MV Pocket project. Source family: https://fonts.google.com/noto/specimen/Noto+Sans+KR . License: NotoSansKR-OFL.txt (Reserved Font Name: Source; this font's name is Noto Sans KR).
- No font subsetting by story text; user-authored Korean, Latin and supported CJK glyphs remain available.
